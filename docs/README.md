# Пилюля — трекер приема лекарств

## Аннотация проекта

**Пилюля** — нативное Android-приложение для отслеживания приема лекарств. Реализует расписание приемов с локальными напоминаниями, учетом остатка и журналом с расчетом приверженности (adherence) за 30 дней.

### Ключевые возможности

- Список лекарств с различными формами (таблетка, капли, сироп, капсула, инъекция)
- Расписание приема: время + дни недели + дозировка
- Локальные напоминания через AlarmManager с action-кнопками (Принять, Отложить, Пропустить)
- Автоматический учет остатка и уведомления о пополнении
- Журнал с adherence-статистикой
- Восстановление будильников после перезагрузки устройства
